LX Plus v25.39 — Free Media Storage
BASE: v25.38 Adaptive Identity
DATA: 12/09/2026

O QUE ENTROU
- Cloudflare R2 como storage gratuito para filmes, episódios e áudios grandes.
- Edge Function privada `lx-r2-media` para URLs assinadas de upload/playback/delete.
- Tela R2 em ADM > Mídia & Upload com salvar/testar credenciais.
- O teste tenta configurar o CORS do bucket para o domínio atual.
- Publicação agora oferece "Enviar arquivo" ou "Usar link externo".
- Mensagens de erro explicam R2 não configurado, CORS, credencial recusada e URL externa inválida.
- Fallback para Supabase apenas para arquivos pequenos quando R2 ainda não está configurado.
- Player e música reconhecem chaves `r2:` e pedem URL temporária para reprodução.
- Ajuste de z-index: o dock global do ADM não cobre mais o modal no celular.

BACKEND
- Edge Function `lx-r2-media` JÁ FOI IMPLANTADA no projeto Supabase atual.
- Nenhuma migração SQL nova é necessária.
- As credenciais R2 ainda NÃO estão cadastradas porque dependem da conta Cloudflare do proprietário.

PUBLICAÇÃO DO FRONTEND
1. Substitua na raiz:
   - index.html
   - app.css
   - lxplus.js
2. Mantenha/substitua:
   - CNAME
   - assets/icon.svg
3. Não reative sw.js nem a pasta js/ antiga.
4. Confirme na autenticação: LX Plus v25.39 · Free Media Storage

ATIVAÇÃO R2
Depois de publicar, siga R2-SETUP.txt. Assim que aparecer "R2 conectado", você já pode enviar os filmes pelo ADM.

ROLLBACK FRONTEND
Se algo inesperado aparecer, volte para v25.38 Adaptive Identity. A Edge Function nova pode permanecer implantada sem afetar a v25.38.
