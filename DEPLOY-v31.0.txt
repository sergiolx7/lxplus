GITHUB PAGES

2. Substitua na raiz do repositório os arquivos do site pelos arquivos do ZIP.
3. Mantenha o arquivo CNAME se o domínio personalizado continuar o mesmo.
4. Após o deploy, faça uma atualização forçada uma vez para trocar o Service Worker antigo.

- migração lxplus_v310_universal_catalog;

As funções antigas lx-content-hub, lx-r2-media e lx-spotify-catalog foram preservadas.

CONFIGURAÇÃO DO IMPORTADOR UNIVERSAL
No site, entre como proprietário/ADM e abra ADM > Importador Universal > Integrações.
- TMDB API Key: necessária para filmes e séries.
- Google Drive API Key: necessária para escanear pastas do Drive.
- YouTube API Key: necessária para o importador em massa do YouTube já existente.

Para o modo Drive por API Key, compartilhe a pasta de forma que a API consiga listá-la. O importador não torna a pasta pública por conta própria.

IMPORTANTE
Não coloque service_role, secret keys ou credenciais privadas em arquivos JavaScript, GitHub ou no navegador.
