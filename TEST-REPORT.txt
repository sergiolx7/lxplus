   - classificação como fonte direta

3. YouTube

   - geração do embed seguro

4. OneDrive
   - leitura do src de iframe
   - aceitação somente de onedrive.live.com/embed

5. Archive.org
   - reconhecimento de /details/ e /embed/
   - geração de player incorporado

6. HTTPS direto
   - validação HTTPS
   - reprodução pelo player LX quando a origem permite

VALIDAÇÕES DE SEGURANÇA / UX
- Link inválido do Drive é rejeitado antes de salvar.
- Fontes não compatíveis com Música/Livro são bloqueadas no formulário.
- O site salva somente IDs/URLs externos; não salva senha de Drive/Dropbox/YouTube/OneDrive.
- Cloudflare R2 continua opcional.
- A Edge Function local de referência lx-r2-media inclui tratamento CORS/OPTIONS; o backend do projeto já recebeu essa correção na versão anterior.

LIMITAÇÕES EXTERNAS (não são bugs da LX Plus)
- O arquivo precisa continuar disponível e compartilhado no provedor.
- Google Drive/YouTube/OneDrive/Archive usam iframe; por isolamento entre domínios, a LX Plus não consegue ler o segundo exato do vídeo nesses players.
- Cada provedor aplica seus próprios limites de armazenamento, tráfego, processamento e compartilhamento.
- Dropbox/HTTPS precisam devolver um arquivo que o navegador consiga reproduzir.
- Para vídeo, MP4 H.264 + AAC continua sendo o formato mais compatível. MKV depende do provedor/player.
