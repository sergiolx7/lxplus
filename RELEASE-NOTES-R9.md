# LX Plus R9 — LX Storage pronto no cadastro

- Endpoint público do LX Storage já vem incorporado na build: `https://lxplus.sergio-sousa.workers.dev`.
- Filmes, séries, animes e doramas novos abrem com **LX Storage / Drive** como fonte padrão.
- No cadastro, basta colar o link normal do Google Drive; não é necessário colar o endpoint novamente.
- Ao colar um link do Drive, a fonte muda automaticamente para LX Storage / Drive.
- Novo indicador **LX Storage conectado** no formulário de publicação.
- Com o LX Storage configurado, o player não volta mais para o iframe/preview do Google Drive. Se o Worker falhar, mostra erro claro em vez da tela de “vídeo sendo processado”.
- Ajuste responsivo da barra de fontes no celular para evitar botões espremidos/cortados.

Para o modo sem credenciais, cada arquivo do Drive precisa estar como **Qualquer pessoa com o link → Leitor**.
