# LX Plus — arquivo da interface v40

Esta pasta guarda a interface visual anterior para consulta e rollback manual durante a reconstrução v41.

Arquivos preservados:
- index.html — shell anterior completo
- lxplus.reference.css — camada visual antiga
- lxplus.reference.js — orquestração visual antiga
- lxplus.rebuild.css — estilos auxiliares da manutenção v40

Os dados reais não ficam aqui. Contas, catálogo, ranking, comunidade e demais dados continuam no Supabase. Os arquivos de mídia e logos continuam em /assets e nos provedores de armazenamento já configurados.

A v41 usa uma estrutura nova de interface e não carrega lxplus.reference.css nem lxplus.reference.js.
