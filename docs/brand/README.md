# Marca LX Plus

Ícone aprovado por Sérgio em 30/10/2026. Criado com a ferramenta de geração de imagens para este projeto, usando uma composição original de olhos em X e sorriso com detalhe de play, em branco/prata sobre preto. O texto `plus` é renderizado pela interface.

O arquivo `lx-face-3d-original.png` preserva o original. As versões WebP e PNG em `assets/` são exportações para cabeçalho, navegador e aplicativo instalável.

## Brief de criação

Carinha abstrata original, confiante e amigável; dois olhos em X formados por traços arredondados com volume, boca curva assimétrica com um pequeno recorte triangular de play, cerâmica branca e reflexos prateados, tile preto arredondado, vista frontal. Sem texto, luz colorida, personagens conhecidos ou referência a marcas externas.
